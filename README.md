# nz-datamap：基督城郊區資料地圖

一個單檔的互動地圖（`christchurch-suburbs.html`），把紐西蘭基督城（Christchurch）各郊區的官方開放資料整理成中英對照，方便比較各區的人口、族群、房價、所得、學校和生活機能。

直接用瀏覽器打開 `christchurch-suburbs.html` 就能使用，不需要安裝或伺服器。所有資料都已內嵌在檔案裡，只有地圖程式庫 Leaflet 從 cdnjs 載入。

## 功能

- **郊區邊界**：141 個郊區與鄉間地區，英文原名加中文音譯，依方位分成 11 個區塊（非官方分區，只是方便溝通）。
- **市議會選區**：可開關的 16 個基督城市議會選區（ward）邊界。
- **郊區詳情**：點任一郊區，側欄會顯示：
  - 人口、密度、年齡中位數與年齡結構
  - 族裔（33 類）與出生地（逐國）
  - 獨立屋比例、自有住宅比例
  - 家戶所得中位數、週租金中位數
  - 獨立屋與土地估價中位數
  - 區內的公立小學
- **公立小學**：122 所，圖示大小依學生人數，顏色區分小學（1–6 年級）、完全小學（1–8 年級）、中間學校（7–8 年級）。點學校可看：
  - 學生數、教師數、師生比、國際學生人數
  - 學生族裔、公平指數 EQI
  - 是否有學區、是否參加免捐款方案
- **數據著色**：選一項數據，各郊區依數值深淺上色，越高越深，並列出最高與最低的 10 個郊區。可選的數據有：
  - 年齡：年齡中位數、各年齡層比例
  - 族群：主要族裔、細分族裔、出生地國家
  - 住房與所得：土地估價中位數、週租金中位數、獨立屋比例、家戶年所得中位數
- **生活地標**：可分類開關的 89 個地點，以及 23 條 Metro 公車路線。地點分為：
  - 交通樞紐、醫院、急症診所
  - 超市、公立圖書館、公立游泳館、大型購物中心
- **距離圈**：以坎特伯雷大學（UC）Ilam 校區為中心的 3 / 6 / 10 公里圈。
- **搜尋**：可搜尋郊區（英文或中文）與學校名稱。
- 支援深色模式與手機版面。

## 計算方式與限制

- **郊區統計**：普查數字以 SA1 小區（約 100–200 人）的代表點落在哪個郊區來加總。Stats NZ 對小數字做了隨機修約，人口少於 300 的郊區比例容易失真，所以不列入排名，也不拿來決定色階範圍。
- **細分族裔與出生地**：這兩項只公開到較大的 SA2 統計區，地圖依 SA1 人口比例把它們分攤到郊區，是估算值。族裔可複選，同一區各族裔加總會超過 100%；出生地每人只算一個國家。
- **中位數**：年齡、所得、租金的中位數是由普查的級距資料內插估算。
- **估價**：只算市議會範圍內的獨立屋（不含公寓、度假屋、空地），Selwyn 與 Waimakariri 沒有公開的逐戶估價，顯示為無資料。
- **色階**：百分比類數據以 0 到上限平均切成 6 格；年齡、地價、租金、所得等數值類數據則讓每一格約佔六分之一的郊區，避免偏態分布擠在同一格。
- **公車路線**：ECan 開放資料最後更新於 2021 年，之後的路線調整可能沒有反映，實際搭車請以 [Metro](https://www.metroinfo.co.nz/) 為準。
- **學校的英語輔導（ESOL）**：官方開放資料沒有逐校的 ESOL 課程資訊，所以沒有列出。
- 地圖沒有街道底圖。要看街道與房子，可點郊區詳情裡的 Google 地圖連結。

中文郊區名稱是音譯，僅供討論使用；正式地址、學區、房屋網站都使用英文名稱。
